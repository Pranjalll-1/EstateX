🏠 EstateX — Real Estate Listings Web App

Live Demo: https://estatex-six.vercel.app

A production‑style real‑estate platform where users can authenticate, create property listings, upload images, and browse categorized offers. Built as a full SPA with Firebase backend services and deployed on Vercel.

Why this project matters

Demonstrates full‑stack ownership (auth → database → storage → deployment)

Handles real user flows (create, edit, delete, session persistence)

Optimized SPA routing with server rewrites (Vercel + React Router)

Clean UI architecture with reusable components and hooks

Key Features

User authentication (Firebase Auth)

Create / edit / delete property listings

Image upload & storage (Firebase Storage)

Offer pricing support

Category filtering (Rent / Sale)

Protected routes & session persistence

Responsive UI (mobile → desktop)

SEO‑safe deployment routing on Vercel

Tech Stack

Frontend: React + Vite + React Router
Styling: TailwindCSS
Backend Services: Firebase (Auth, Firestore, Storage)
Hosting: Vercel
